## 技术架构

### 系统架构图
```
用户界面层（前端）
    ↓
API 路由层（FastAPI）
    ↓
智能路由器（自动决定单/多智能体）
    ↓
Model Adapter 层（统一输出格式）
    ↓
Task Evaluator 层（任务复杂度评估）
    ↓
Simplified Agent Orchestrator 层
    ↓
模型层（豆包、DeepSeek R1、Llama 3.1）
    ↓
工具层
```

### 核心组件

1. **ModelRouter** - 模型路由器
   - 统一管理多个模型
   - 支持云模型和本地模型
   - 按需创建模型实例

2. **ModelOutputAdapter** - 模型输出适配器
   - 统一不同模型的输出格式
   - 支持推理链提取
   - 支持多种模型类型

3. **TaskComplexityEvaluator** - 任务复杂度评估器
   - 快速评估（基于规则）
   - 详细评估（基于模型）
   - 成本效益分析

4. **SimplifiedOrchestrator** - 简化协调器
   - 单智能体模式处理
   - 多智能体模式处理
   - 任务分解和并行执行
   - 结果合并

## 使用方式

### 启动后端服务
```bash
conda activate langgraph-env
cd D:\AI\AIcode\MyPrivateAgent\backend
python main.py
```

### 访问前端界面
- 登录页: http://localhost:8000/login
- 主页面: http://localhost:8000/index

### 功能使用
1. 选择模型：豆包、Llama 3.1、DeepSeek R1、LLaVA
2. 开启推理显示：勾选"显示推理过程"（仅支持 DeepSeek R1）
3. 发送消息：系统自动判断使用单智能体或多智能体模式
4. 查看结果：实时流式输出，显示处理过程
