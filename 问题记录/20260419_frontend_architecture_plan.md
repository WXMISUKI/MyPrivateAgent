- **优先级**: 🔴 高

---

## 一、项目概述

### 1.1 背景

当前 MyPrivateAgent 前端使用原生 HTML/CSS/JavaScript 架构，随着功能增加，存在以下问题：
- 代码组织混乱，维护困难
- 样式不统一，主题切换复杂
- 流式渲染体验有待提升
- 响应式设计不完善

### 1.2 目标

1. **现代化设计** - 借鉴 Claude Code、ChatGPT、Claude 等成熟产品
2. **模块化架构** - 组件化开发，代码复用
3. **优秀体验** - 流畅的动画，清晰的交互
4. **主题支持** - 亮色/暗色主题切换
5. **响应式布局** - 适配桌面、平板、手机

## 四、功能模块设计

### 4.1 顶部栏 (Header)

```
┌─────────────────────────────────────────────────────────────────┐
│ [🤖 Logo] [🔍 搜索会话...]                    [⚙️] [🧠] [👤] [🌙] │
└─────────────────────────────────────────────────────────────────┘
```

**功能**：
- Logo + 产品名称
- 全局搜索（搜索会话内容）
- 设置按钮
- 学习记录入口
- 用户菜单
- 主题切换

### 4.2 侧边栏 (Sidebar)

```
┌────────────────┐
│ [+ 新建对话]   │
├────────────────┤
│ 今天           │
│   • 会话1      │
│   • 会话2      │
├────────────────┤
│ 昨天           │
│   • 会话3      │
├────────────────┤
│ 更早           │
│   • 会话4      │
├────────────────┤
│ [🧠 学习记录] │
│ [📊 统计]     │
│ [⚙️ 设置]     │
└────────────────┘
```

**功能**：
- 新建对话按钮
- 会话分组（今天/昨天/更早）
- 会话列表（显示标题+时间）
- 悬停显示操作菜单（删除、重命名）
- 底部功能入口

```
┌──────────────────────────────────────────┐
│ [🤖 DeepSeek R1 ▼] [🧠] [📊] [🔧]      │
└──────────────────────────────────────────┘
```

**功能**：
- 模型下拉选择
- 推理开关（显示/隐藏思考过程）
- 上下文状态指示
- 工具调用日志

  ↑ 左对齐，深色背景，代码高亮

### 4.5 输入区域

```
┌──────────────────────────────────────────────────────────────┐
│ [📎] │ 输入消息，Shift+Enter 换行...              │ [⏎️] │
└──────────────────────────────────────────────────────────────┘
```

**功能**：
- 文件上传按钮
- 多行输入
- 发送按钮（可使用 Enter 发送）
- 字符计数
- 发送中显示加载动画

### 4.6 快捷命令

输入框支持斜杠命令：

| 命令 | 功能 |
|------|------|
| `/new` | 新建对话 |
| `/clear` | 清空当前对话 |
| `/model [name]` | 切换模型 |
| `/theme` | 切换主题 |
| `/export` | 导出对话 |
| `/skills` | 打开 Skills 管理 |

## 五、交互设计

### 5.1 动画效果

| 交互 | 动画 |
|------|------|
| 按钮悬停 | scale(1.02) + 颜色变化，150ms ease |
| 消息出现 | fadeIn + slideUp，300ms ease-out |
| 思考展开 | height + opacity，200ms ease |
| 侧边栏切换 | translateX，250ms ease |
| 主题切换 | 全局过渡 300ms |

### 5.2 流式输出

```
助手: 我是        →  我是 D       →  我是 Deep  →  我是 DeepSeek
     [光标闪烁]      [光标闪烁]       [光标闪烁]      [完成]
```

**特点**：
- 光标闪烁表示正在输入
- 渐进式显示
- 代码块即时渲染
- Markdown 实时解析

### 5.3 加载状态

| 状态 | 显示 |
|------|------|
| 思考中 | 🧠 思考中... + 光标 |
| 生成中 | ⏳ 正在生成... + 光标 |
| 发送中 | 发送按钮旋转 |
| 加载历史 | 骨架屏 |

### 5.4 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 网络错误 | 显示重试按钮 + 错误消息 |
| 模型错误 | 显示具体错误 + 建议 |
| 超时 | 自动重试 + 提示 |

## 六、响应式设计

### 6.1 断点

| 设备 | 宽度 | 布局 |
|------|------|------|
| 桌面 | > 1024px | 三栏（侧边栏+对话+详情） |
| 平板 | 768-1024px | 两栏（侧边栏可隐藏+对话） |
| 手机 | < 768px | 单栏（全屏对话） |

### 6.2 移动端适配

- 侧边栏变为底部导航或抽屉
- 输入框固定在底部
- 消息区域占满屏幕
- 支持手势操作（滑动手势切换会话）

## 七、技术实现方案

### 7.1 推荐技术栈

**方案A：保持原生 JS（当前方案优化）**

| 优点 | 缺点 |
|------|------|
| 无需构建步骤 | 代码组织困难 |
| 快速迭代 | 状态管理复杂 |
| 体积小 | 组件复用性差 |

**方案B：Vue.js 3 + Vite（推荐）**

| 优点 | 缺点 |
|------|------|
| 组件化开发 | 需要构建步骤 |
| 响应式数据 | 学习成本 |
| 生态丰富 | 体积较大 |
| 调试友好 | 迁移成本 |

**方案C：React 18 + Next.js**

| 优点 | 缺点 |
|------|------|
| 生态最成熟 | 配置复杂 |
| SSR 支持 | 学习成本高 |
| TypeScript 友好 | 体积大 |

### 7.2 推荐：渐进式迁移

考虑到当前项目已经有一定规模，建议：

**阶段1**：保持原生 JS，优化代码结构
- 模块化组织 JS
- CSS 变量重构
- 统一设计系统

**阶段2**：引入 Vue.js（可选）
- 组件化关键模块
- 状态管理
- 路由管理
