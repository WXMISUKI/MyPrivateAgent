# Task

根据输入的表格数据，逐步分析并输出危大工程识别结果。

## 执行步骤

### 1. 意图理解
首先说明你理解了用户的需求。

### 2. 数据概览
说明输入数据的基本情况：
- 数据来源（文件名/直接输入）
- 表格结构（列数、行数）
- 关键字段识别

### 3. 逐条分析
对每一行数据：
- 提取原始方案名称
- 匹配标准名称（说明匹配逻辑）
- 判定类别
- 判定是否超危大（说明判定依据）

### 4. 输出结果
最终输出 JSON，必须遵守：
1. `id` 使用原表格编号并转成字符串；没有编号时为 `null`。
2. `originname` 保留原始完整方案名称，不得删减。
3. `name` 使用标准危大工程名称；无法匹配时为 `未分类`。
4. `category` 使用标准映射类别；无法匹配时为 `未分类`。
5. `isExdanger` 只能是 JSON 布尔值 `true` 或 `false`。
6. 专家评审字段为 `是` 时，视为显性专家论证/评审信号，`isExdanger = true`。
7. 输出必须是合法 JSON 对象，不要包裹代码块。
