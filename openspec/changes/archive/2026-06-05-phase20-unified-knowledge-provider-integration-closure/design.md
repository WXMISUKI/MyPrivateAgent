## Overview

Phase 20 is a closure slice, not a feature-expansion slice. It consumes the repo-side trial outcome generated by Phase 19 and emits a stable integration decision:

- `go`: the minimal provider access path is ready and the next line may move to grounding policy or integration hardening.
- `review`: optional evidence or non-blocking readiness context still needs human review, but the readiness evidence chain should not expand by default.
- `blocked`: required trial or provider contract checks failed, so caller-side integration must wait.

## Data Flow

```text
Phase 19 trial outcome json
        |
        v
Phase 20 closure decision builder
        |
        +--> docs/integration/.../phase20-integration-closure-decision.json
        |
        +--> docs/integration/.../phase20-integration-closure-decision.md
```

## Decision Inputs

- Phase 19 trial `status`.
- Phase 19 trial `decision`.
- Required check statuses:
  - `provider_health`
  - `provider_manifest`
  - `provider_preflight`
  - `source_bindings`
  - `rag_retrieve`
- Boundary state:
  - source binding policy owner remains caller-owned.
  - runtime promotion remains unchanged.
  - default chat retrieval injection remains disabled.
  - GraphRAG execution is not promoted unless explicitly proven by a later gate.

## Decision Rules

- Emit `go` when:
  - Phase 19 status is `trial_passed`.
  - Phase 19 decision is `proceed_with_myprivateagent_integration_hardening`.
  - All required checks are `ready`.
  - Runtime promotion status is `unchanged`.
- Emit `blocked` when:
  - Trial status is `trial_blocked`, or any required check is `blocked`.
  - The trial artifact is missing or invalid.
- Emit `review` otherwise.

## Ownership Boundaries

MyPrivateAgent owns the closure decision, caller-side readiness interpretation, future grounding policy, and default chat promotion gate. The provider owns ingestion, retrieval implementation, source catalog, graph schema discovery, and GraphRAG execution readiness.

## Verification

- Focused tests cover `go`, `review`, and `blocked` closure decisions.
- Existing Phase 19 trial tests remain passing.
